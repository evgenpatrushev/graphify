## Real findings captured this run (grounded in live runs)

- **Node schema:** real nodes are `{id, label, file_type, source_file, source_location}`.
  There is **no `node_type` field** — `file_type` (`code`/`document`/`concept`) is the
  discriminator. Documented in PIPELINE_GUIDE.
- **`extract_python(diff.py)`** → 32 nodes, 111 edges (relations: contains, imports,
  imports_from, calls, references, rationale_for).
- **`build_from_json`** collapses parallel edges in a simple Graph: 111 edges → 77.
  (On disk it reloads as a MultiGraph — the reason `diff.py` needs `_edge_relations()`.)
- **`cluster()` on a 32-node graph → 0 communities** (too small to partition). Expected;
  clustering only pays off on a full-corpus graph.
- **Current `graphify-out/graph.json`** is the AST-only build: 1305 nodes, 1238 edges,
  `contains`-dominated (1180/1238), **0 nodes have a `community` attr**. This confirms
  why `diff` shows sparse ripple — behavioral edges + communities need the semantic pass.
